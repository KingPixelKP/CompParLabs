# Processing DataFrames With Spark

This lab is an introduction to DataFrame processing with the Apache Spark framework for Parallel Data Processing in distributed environments. The environment uses the Python language through the `pyspark` module.

## 🛠️ Setup

To prepare the working environment, you can choose one of the following options:

* Use the local Python installation (the same one used in lab01).
* Update the Docker environment in the `docker-compose.yml` file of the `compar-spark-docker` project to include the notebook and data folders for this project.

You will most likely have to install packages: matplotlib, matplotlib-inline, pandas and pyarrow.
